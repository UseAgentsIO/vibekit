# vibekit

CLI for initializing Projects, installing Modules, and validating composition.

```bash
vibekit init [dir]
vibekit add <type> <name> --yes
vibekit list
vibekit doctor
```

`--yes` skips confirmation. `--registry <path>` selects a registry root. `--dir <path>` selects the Project root for `add`, `list`, and `doctor`.
